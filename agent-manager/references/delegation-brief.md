# Format brief delegasi

Gunakan template ini setiap kali mendelegasikan tugas ke agent.

```
AGENT: <research | writer | editor | planner | coder | reviewer>

TUJUAN
<satu kalimat: apa yang harus dihasilkan dan untuk apa>

KONTEKS
<hanya yang relevan: audiens, platform, gaya bahasa, stack, keputusan sebelumnya>

INPUT
<bahan yang diberikan: teks, tautan, file, hasil agent sebelumnya (ringkas)>

BATASAN
<panjang, nada, bahasa, library yang boleh/tidak boleh, deadline>

FORMAT OUTPUT
<bentuk hasil yang diminta, misalnya: 3 opsi judul + 1 naskah 60 detik>

KRITERIA SELESAI
<bagaimana manajer menilai hasilnya sudah cukup>
```

## Contoh singkat

```
AGENT: writer

TUJUAN
Tulis script video TikTok 45 detik tentang manfaat belajar vibe coding untuk pemula.

KONTEKS
Audiens: pelajar dan pekerja non-teknis. Gaya santai, bahasa Indonesia.

INPUT
Tiga poin dari agent research: (1) tanpa perlu hafal sintaks, (2) cepat bikin prototipe, (3) tetap perlu paham logika dasar.

BATASAN
Maksimal 110 kata. Hook di 3 detik pertama. Tanpa istilah teknis yang rumit.

FORMAT OUTPUT
Script per adegan: teks ucapan + catatan visual singkat.

KRITERIA SELESAI
Ada hook, tiga poin tersampaikan, ada ajakan bertindak di akhir.
```
